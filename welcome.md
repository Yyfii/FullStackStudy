### General terms

`Client` : refers to any device or application that receives services or uses resources over a computer. Typically represents the party that requests a specific service or resource by communicating with a server.
In web development, the term client refers to the user´s computer or browser.

Your `browser` acts as a client for websites. The web browser connects to a server. A Website server retrieves pages upon request and then displays them on the user´s computer.

A browser is a computer program that enables users to navigate the internet, view websites, and access various online content. Ex: Google Chrome, Mozilla Firefox, Safari, and Opera as well.

Web browsers actually allow users to be directed to the desired websites by typing `URL`s, which is an abbreviation for Uniform Resource Locators.
Browsers interpret web pages using web technologies such as HTML, CSS, and JavaScript and then present them visually to users.

`Web hosting` refers to the service necessary for making website or web application accessible on the internet. Include hosting, storing and making website files accessible. The service is provided by a hosting provider, and is typically used through a subscription model or a payment for a specif period of time.

You got your server where the websites and applications are hosted on a server. The server is just that computer system that stores the files of websites and allows users to access these files. The server will have storage space to store the files of the website, the html pages, images, videos, databases, all the stuff.
The storage space is typically located in large data centers.
